Paperweight OG backgrounds

Background-only PNGs. Text, badges, logo, radar, desktop frame and screenshots
are rendered separately by src/utils/og.tsx with Next.js ImageResponse / Satori.

Renderer: Chrome for Testing 153.0.8010.12, captured through Playwright.
Reproduce at a 1200x630 viewport, deviceScaleFactor 1. Render the following
absolute-positioned layers in order. html and body have margin: 0,
width: 100%, height: 100%, overflow: hidden. Use page.setContent() with these
layers and page.screenshot({ path: outputFile }) after loading the HTML.

These fixed background-only assets preserve the original Chromium dot mask
and soft glow. Keep them rather than adding runtime browser rendering or a
second, approximate Satori implementation of the same backdrop.

.background {
  position: absolute;
  inset: 0;
  background: linear-gradient(135deg, #2b3440 0%, #1a1f27 100%);
}

.glow {
